# 工具写作规范

这个工具本身不干活，它是一份给 Agent 看的说明书：怎么给 TeacherBox 写一个新工具。

同一份内容，两种格式，在 `tools/agent-spec/` 里：

- `agent-spec.md`
- `agent-spec.txt`（内容与 md 完全一致，个别平台不让传 md 时用这个）

两个按钮的用处：

- **打开 TXT**：用记事本打开 `agent-spec.txt`，方便直接拷走。
- **复制 MD 到桌面**：把 `agent-spec.md` 复制一份到桌面，文件名 `TeacherBox-工具规范.md`，可以整份丢给别的 Agent。

要装新工具，除了照规范自己写，也可以直接到「工具市场」下载，或者把 zip 拖进窗口。
